# AMORAH CALC

### Mathematical Computation Engine

AMORAH CALC is a modern, browser-based, mathematical computing engine designed to go beyond the traditional calculator.
The goal is to build a mathematical laboratory capable of understanding mathematical expressions, performing calculations, solving advanced problems, and eventually explaining solutions step by step.

## Project Vision

AMORAH CALC is being built from the ground up using JavaScript, with mathematics at the center of the system.
Instead of relying on `eval()` or simply connecting a calculator interface to an external library, Amorah is designed to understand mathematical expressions through its own processing pipeline.
